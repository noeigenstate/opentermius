Grayscale wireframes of every screen, built to approve layout, hierarchy and states before colour. Frames are drawn at 1550×1015 and scaled to the window (use 100 % for actual size). Numbered pins refer to the notes under each frame. Placeholder data only: documentation addresses (192.0.2.0/24, 198.51.100.0/24), user root. Palette: ten neutrals --g0 … --g9; no hue anywhere. Where the mockup uses colour for state, a non-colour encoding is used (fill, weight, border, icon, label). Questions and changes are collected in section 11.

5a · Tab anatomy — corrected

The reported bug: ⋯ and × are text glyphs (⋯ ×) whose baseline and size depend on the font, so × lands ~5 px below the tab midline. Fix: both actions are SVG icons of identical size on the same 24-px grid, in 24×24 boxes that are centred by align-items:center.

BEFORE · text glyphs (4×)
AFTER · SVG icons, one midline (4×)
  1. 1

  2. 2
    Icon box 20×20 box, centre = tab midline (y = 20). Holds a 10 px status dot or a 16 px prompt icon (local terminal); both are centred inside the box, never offset with margins.

Tokens

  • --ease-out: cubic-bezier(.2,.75,.25,1) (enter, hover)
  • --ease-in: cubic-bezier(.4,0,1,1) (exit)
  • Durations: 0 · 70 · 120 · 150 · 180–220 · 280 · 600 ms. Nothing above 600 ms.

Global rules

  • prefers-reduced-motion: reduce removes transforms and shortens/removes fades, as listed per row; state changes stay visible through fill, weight and icons.
  • On window blur or hidden document, finite decorative animation is disabled and final static content shown (existing data-motion-paused mechanism).
  • Hover effects only under (hover: hover) and (pointer: fine).
  • Replaces today’s 3D tilt on buttons (perspective + rotateX) with the 1 px lift + press scale from the mockup spec (D14).
  • Reduced transparency / forced colours: scrims stay opaque enough, outlines replace shadows (unchanged from today).
